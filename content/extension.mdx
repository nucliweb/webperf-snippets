# DevTools extension

A Chrome DevTools panel that runs the snippets on the inspected page and shows their results: the metric and its rating, the issues with how to fix them, and the items as a table. It runs the same code as the CLI and the agents, without pasting anything into the console.

## What it does

- Lists the 56 snippets by category, with a search (`/`), and runs the chosen one on the inspected page (`Ctrl` `Enter` or `Cmd` `Enter`).
- Shows each result by the [return contract](https://github.com/nucliweb/webperf-snippets/blob/main/snippets/SCHEMA.md): the metric and its rating, the issues sorted by severity, the items as a table and the details. A selector in the result opens its element in the Elements panel.
- Runs snippets that record what happens, such as INP or long animation frames: run it, use the page, then press Read result.
- Runs a structural audit: the 22 snippets of the [CLI](/CLI) audit workflow, one after the other, on a page it reloads first, as the CLI loads it. The table opens on the snippets with errors or warnings, to keep them in focus; Errors and All change the rows it shows, and the panel remembers the choice. Each audit says what changed since an earlier audit of the same page, the previous one unless you choose another: tables of new, changed and resolved issues, paired by their code and the resource they name, and of metrics whose rating moved. A changed issue shows only the numbers that moved, and an issue whose severity moves is a change. The panel keeps the last ten audits.
- Copies a result as JSON, and downloads an audit as JSON in the shape of `--workflow audit --json`.
- Copies two prompts for an AI agent. Prompt to measure runs the snippet with the CLI, with the inspected page in its command. Prompt to fix, on a result or an audit with errors or warnings, is for an agent that works in the repository of the site: it carries the issues with their code and the resource they name, the details and the rows they point to, and asks the agent to check the fix with the CLI before and after the change, on a URL where the change can be tested.
- Works on pages whose Content Security Policy blocks code pasted into the console, since it runs the snippets through the DevTools API.

## Install the beta

The extension needs Chrome 120 or later.

1. Download the zip and unzip it. Keep the folder: Chrome loads the extension from it.
2. Open `chrome://extensions` and turn on **Developer mode**, at the top right.
3. Choose **Load unpacked** and select the unzipped folder, the one with `manifest.json`.
4. Open DevTools on any page and go to the **WebPerf Snippets** panel. If it is not in sight, it is in the `»` menu of the panels.

To update it, download the new zip, remove the extension in `chrome://extensions` and load the new folder.

## Privacy

The extension asks for no permission beyond storage, and runs a snippet only when you press Run or start an audit. It sends nothing anywhere: the results stay in the panel, the last audits in the local storage of the browser, and the settings, the theme and the side of the list, in the storage that Chrome syncs with your account.

## Limitations

- It is a beta: expect rough edges.
- It runs in Chrome. Firefox and Safari versions come later, if there is interest.
- The snippets ship inside the extension, so a new version of a snippet arrives with a new version of the extension.
- The [DevTools Overrides](/DevTools-Overrides) scripts are not in it: they run before the page, from Local Overrides.
